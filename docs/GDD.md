### 0.3 五条设计铁律（违反即打回）

1. **聚合模拟**：人口按阶级聚合，不模拟个体；物资按 5 类聚合，不做 20 种矿物。个体只用于名人。
2. **三条公式**：转化（公式一）、价格（公式二）、满意（公式三）。任何新玩法必须能写成「三条公式 + 耦合表的一行」，写不成就不进主线（做 DLC 或砍掉）。
3. **因果可读**：任何数值变化，UI 必须能展开成「结果 ← 公式 ← 各项数值」。玩家要能说清「为什么粮价涨了」。
4. **抽卡不破坏策略**：随机提供**方向**，不提供**免死**。所有随机都有稀有度、保底与可查看概率；同种子同命令流必须得到位级相同结果。
5. **Core 稳定、插件扩展、数据驱动**：加第 9 个阶级、加时代卡包、加新形胜 = 加数据文件，不改 Core 代码。

## 1. 产品定位

### 1.1 玩家幻想

你不是在点建筑，你是在**治理一个有脾气的社会**：

- 你下令加税，太守可能上书骂你，然后只收上来六成；
- 你抽到一个理政 96 的名臣，他顺手把经济做起来了，也顺手贪了三成；
- 你放任工业扩张，工人多了、粮价飞了、农民破产、商人囤粮，最后城门被自己人堵了；
- 你掐住上游的水坝，下游三座城减产，然后收到一封措辞礼貌的宣战书。

### 1.2 核心体验三件事

1. **看懂因果**：每回合结束有一份「因为 A，所以 B」的年度报告；任何数字都能点开看链条。
2. **抽卡的快乐**：人物、科技、事件、名作、地貌发现、教义——六类卡池，有稀有度、有保底、有「这一抽改变这局 Build」的时刻。
3. **做取舍**：没有任何政策能让八个阶级同时满意。玩家永远在选「这回合让谁不高兴」。

### 1.3 核心循环（一年一圈）

```
看年报 → 定国策（花 AP）→ 抽/任名人 → 调税与贸易 → 建/升级设施
   ↑                                                        ↓
   └──────── 结束回合：四季结算 → 阶级反应 → 事件 → 新一年 ┘
```

### 1.4 单局规模

| 项 | 垂直切片（首个可玩版） | 正式版 |
|---|---|---|
| 地图 | 32 × 20 六边形（约 640 格） | 64 × 40（约 2560 格） |
| 玩家 | 1 人 + 2 AI | 1–8 人（联机 2–8） |
| 城镇 | 4–6 座 | 20–40 座 |
| 阶级 | 农民 / 工人 / 商人（框架八阶级齐备） | 八阶级全开 |
| 回合 | 120 年 | 200 年（可无尽） |
| 单局时长 | 45–60 分钟 | 4–6 小时（联机 3 次 2 小时） |

### 1.5 胜利与结束

不设唯一胜利。第 200 年（或触发阈值）结算，三轴加权：

| 轴 | 构成 | 权重 |
|---|---|---|
| 霸业 | 控制人口 + 附庸数 + 关键形胜（隘口/河口）数 | 0.40 |
| 繁荣 | 贸易网络中心度 + 国库 + 人均产出 | 0.35 |
| 文明 | 科技完成度 + 文化辐射 + 名作数 | 0.25 |

阈值速胜（任一达成即结束）：军事（控制全局 45% 人口且敌国首都陷落）、经济（连续 10 年贸易顺差第一且国库 ≥ 20 倍年支出）、科技（点满一个时代全部科技卡）、文化（3 座他国/独立城镇和平归附）、外交（过半国家加入你主导的同盟）。

## 2. 时间与回合

### 2.1 粒度：一回合 = 一年

农业、税收、人口、征兵都以年为单位才有意义；月 tick 会让一局变成 2000+ 回合，联机与调参都不可行。**季节只存在于结算内部，不是玩家操作单位。**

### 2.2 回合结构（意图 + 四季）

| 段 | 玩家做什么 | 系统做什么 |
|---|---|---|
| 意图（春前） | 花 AP 下命令：政策、建设、任命、外交、军事调动、抽卡 | 校验合法性；AI 与官员同时提交意图 |
| 春 | — | 播种、开工、人口流动申请、宣战生效 |
| 夏 | — | 生产、城际/国际贸易、行军与战斗、灾害判定 |
| 秋 | — | 收获、市场出清、税收、俸禄军饷 |
| 冬 | — | 消费、满意度、阶级状态迁移、名人事件、年度报告、存档 |

### 2.3 固定结算顺序（`SIM_ORDER.md` 的正文）

顺序不可调换；插件只能往这些步骤上挂 hook，不能插队。

1. 应用已批准的命令与政策（扣 AP）
2. 建筑与设施生效/完工
3. 农业产出（春播秋收的净效果）
4. 工业生产（含原料约束）
5. 服务与非物质产出（信仰/知识/文化/行政）
6. 城镇市场出清（公式二，本地层）
7. 国内贸易（运输成本加权，国家级市场层）
8. 国际贸易（关税、关系、封锁）
9. 工资、利润、俸禄、军饷发放
10. 阶级消费与需求满足率
11. 税收与财政结算（含腐败漏损）
12. 满意度更新与阶级状态迁移（公式三）
13. 人口增长、阶级转化、城镇间迁移
14. 军事结算（补给、战斗、占领）
15. 外交、名人诉求、事件抽取、年度报告、快照存档

> 顺序的因果含义：**先生产再分配再消费**，所以「今年歉收」影响的是「今年的价格与明年的满意度」，不会出现同年自噬。

### 2.4 时代

| 时代 | 进入条件 | 解锁内容 |
|---|---|---|
| 城邦 | 开局 | 农民/工人/商人，基础形胜 |
| 古典 | 科技卡 ≥ 6 | 祭司、官僚；神庙、城镇中心 |
| 官僚帝国 | 科技卡 ≥ 13 | 学者、军人；学宫、兵营、道路网 |
| 商业革命 | 科技卡 ≥ 21 | 文艺家；银行、股份、远洋 |
| 工业前夜 | 科技卡 ≥ 29 | 火器、铁路、工厂（终局） |

时代只做**解锁闸门**，不做数值倍增器——数值来自科技卡本身。

### 2.5 玩家操作预算

每回合的「可做多少事」由 **AP（政令点）** 约束（§6.3），不是由点击次数约束。AP 不足时命令**打折执行**而不是禁止，这是本作的核心手感之一：帝国边界由官僚数量与廉洁度决定。

## 3. 世界与地图

### 3.1 五层地块模型

一个地块 = 五层数据，每层只回答一个问题。**不要用枚举把地形、资源、地貌做成互斥类型。**

| 层 | 取值 | 回答的问题 | 是否可改 |
|---|---|---|---|
| 地表 | 平原/草原/森林/丘陵/山地/湿地/荒漠/冻土/海岸 | 基础潜力与通行成本 | 不可（火山事件除外） |
| 水体 | 无 / 河（边，有向+流量）/ 湖 / 海（近海、深海） | 水运、断水、渔业、隔绝 | 可筑坝、可填 |
| 形胜 | 盆地/山谷/隘口/河口/三角洲/上游高地/峡谷/湖岛/绿洲/盐湖/冲积扇/火山 | 战略锚点 | 不可 |
| 资源 | 铁/马/盐/香料/渔汛（可空，**门槛标签**，不是新货币） | 能造什么、上限多少 | 不可（矿脉可枯竭） |
| 人造 | 道路/驿/城/关城/堤坝/船坞/矿场/农田/种植园 | 玩家的物理意志 | 可建可毁 |

### 3.2 地表表

| 地表 | 粮潜力 | 料潜力 | 通行成本 | 防御 | 备注 |
|---|---:|---:|---:|---:|---|
| 平原 | 3 | 0 | 1 | 0 | 最佳农地与建城地 |
| 草原 | 2 | 1 | 1 | 0 | 农牧兼备，骑兵适地 |
| 森林 | 1 | 3 | 2 | +1 | 伐木，步兵隐蔽 |
| 丘陵 | 1 | 2 | 2 | +1 | 矿脉高发，远程视野 +1 |
| 山地 | 0 | 3 | 4 | +2 | 屏障，仅隘口/山谷可穿 |
| 湿地 | 1 | 1 | 3 | −1 | 疫病风险，骑兵禁用 |
| 荒漠 | 0 | 1 | 2 | 0 | 商路与稀有矿 |
| 冻土 | 0 | 1 | 2 | 0 | 低人口，皮毛 |
| 海岸 | 2 | 0 | 1 | 0 | 可建港口，外贸入口 |

水域：湖（粮 2，淡水）/ 近海（粮 1，港口）/ 深海（需航海科技）。

> 潜力是**产能上限**，不是白拿的产出（§4.2）。没有人口和设施，地块不生钱——这一条挡住「无人口自动产出」的经典 bug。

### 3.3 河流：地块边上的有向图

```
河 = 一组边 { fromTile, toTile, flow, width }
source → … → lake / sea
```

三条推论（全部是玩法，不是风味）：

1. **水运**：沿河运输成本 ×0.4；河运节点自然长出税关与商城。
2. **梯度传导**：上游筑坝/取水/排污按比例削减下游 `flow`；下游粮潜力与卫生（疫病率）随 flow 变化。玩家能看见「上游修坝，下游三镇减产」。
3. **渡口与桥**：跨河行军消耗 +1 移动并受 −20% 战力惩罚；渡口/桥是稀缺格，战斗与贸易同时被卡。

### 3.4 形胜表（12 种，程序化识别）

生成后扫描拓扑关系自动打标签；同标签可叠加在地表上（例：山地 + 隘口 = 关城位）。

| 形胜 | 识别规则 | 经济 | 军事/政治 |
|---|---|---|---|
| 盆地 | 环形高地包围 8–20 格低地 | 内部粮潜力 ×1.3，人口上限 +30% | 仅 1–2 出口，断粮可破；易成文化孤岛 |
| 山谷 | 两山夹 6–15 格长槽 | 料潜力 ×1.2 | 走廊行军，两侧高地可射击；一队可锁谷 |
| 隘口（山水夹缝） | 河或路切穿山脊的 1–2 格孔洞 | 可设税关，过路费 | 全图最强防御位（防御 +3）；谁占谁定国界 |
| 河口 | 河入海 | 渔 + 外贸双加成，最佳建城点 | 封锁河口 = 掐死一国进出口 |
| 三角洲 | 大河末端 | 粮潜力 ×1.5（全图最高） | 每 8–20 年一次洪水（高风险高回报） |
| 上游高地 | 河源头段 | 粮一般 | 可筑坝 → 对下游断水，天然外交火药桶 |
| 峡谷 | 深窄河谷 | 可筑坝 → 器产出 ×1.2 | 天然关城位 |
| 湖岛/半岛 | 湖中或海中 | 粮低但免灾害 | 学宫/神庙加成；陆军不可直取 |
| 绿洲 | 荒漠中成串 | 补给点，粮潜力 ×1.5（局部） | 控制绿洲 = 控制穿沙商路 |
| 盐湖 | 内流湖末端 | 盐（早期算奢，后期算必需） | 盐铁专卖的载体 |
| 冲积扇 | 山前坡地 | 需改良才高潜力 | 「人定胜天」科技线的投资标的 |
| 火山 | 稀有 | 料潜力 ×1.5 | 信仰圣地；喷发事件 |

### 3.5 门槛资源（不是第 6 种商品）

| 标签 | 作用 | 缺失后果 |
|---|---|---|
| 铁 | 重步/攻城/矿场升级 | 只能轻步与民兵 |
| 马 | 骑兵/驿传速度 | 无骑兵，机动劣势 |
| 盐 | 早期奢侈品、食物保存 | 奢产出上限 −50%，冬季粮损耗 +10% |
| 香料 | 奢侈品溢价、宗教仪式 | 奢价格上限 −30% |
| 渔汛 | 湖海粮潜力 +1 | 沿海城镇粮自给不足 |

资源只在**门槛与倍率**上出现，不进入 5 物资的库存表。这样资源表永远 5 行。

### 3.6 地块三属性

对外只暴露三个可计算量，规则书三行讲完：

```
Y_g   = 地表潜力_g × 形胜倍率_g × 资源倍率_g × 水利系数
C     = 地表通行成本 × 形胜修正 × (道路 ? 0.6 : 1) × (水运 ? 0.4 : 1)
D     = 地表防御 × 形胜防御 × (工事等级 + 1)
```

- `Y_g` 只对 `g ∈ {粮, 料}` 有意义；器/奢由城镇加工而来。
- 改良（农田/矿场）不进 `Y`，而是进 §4.2 的设施系数，避免同一加成算两遍。
- 水利系数：河/湖相邻 1.15，堤坝 1.25，断水 0.5–0.8。
- 城镇把半径 2 内、最多 12 格绑定为自己的「辖地」，`辖地 ΣY` 即该镇产能上限（§4.2）。

### 3.7 地图生成管线（六步，固定种子可复现）

1. 大陆轮廓（噪声 + 边缘衰减）
2. 海拔与山脊
3. 河流与湖泊（沿高程下降，保证入海或入湖）
4. 温度/降水 → 地表
5. 地质 → 资源标签
6. 形胜识别 + 出生点公平性修正

**公平性校验（不通过就重生成）**：

- 每个出生点半径 3 内粮潜力 ≥ 8；
- 每个玩家附近至少 1 种门槛资源；
- 不保证资源相同（差异是玩法），但保证**没有死局**；
- 至少 3 处可建的盆地/河口/隘口级战略点，且不全在同一个玩家门口；
- 河流连通性检查：无孤立内陆湖。
- 生成器版本号写入存档；升级生成器必须升版本并能识别旧档。

### 3.8 建城

| 条件 | 值 |
|---|---|
| 位置 | 非山地/深海/冰川；距最近城镇 ≥ 3 格 |
| 成本 | 料 12 + 器 4 + 银 40 + AP 3 |
| 初始人口 | 4（农民 4） |
| 辖地 | 自动绑定半径 2 内最多 12 格 |
| 限制 | 每国每 5 年最多新建 1 城；人口 < 3 的城镇 3 年内不增长则废弃（鬼城回收） |

### 3.9 地图尺寸与图层

图层（可切换）：地形 / 资源 / 人口密度 / 阶级分布 / 贸易网络 / 军事态势 / 信仰 / 文化影响 / 控制权。图层是纯查询，不改状态。

### 4.2 八阶级统一模板（八段代码 = 八行数据）

所有阶级共用同一套公式，差异只来自数据。**不允许给某个阶级写特判逻辑。**

> 「每个阶级是独立子系统」不等于「每个阶级写一套代码」：产出、收入、消费、满意、政治分量这条闭环由同一模板驱动，但 `λ`、需求篮子、解锁条件、组织度来源、专属功能与矛盾标签全部独立配置。新增第 9 个阶级 = 新增一个 JSON + 必要时一个 hook，不动模板。

```
劳动力        L_c   = P_c × λ_c
产出          Out_c = min( P_c × λ_c × Tech × η(S_c) , Cap_c × Facility_c )
Facility_c  = 1 + 0.15 × 产业设施等级（上限 1.45）
产能上限      Cap_c = Σ(辖地 Y_g × 阶级适配)          // 农民适配粮+料，工人适配料
需求          Need_c = P_c × 需求篮子_c
满足率        s_c   = min(1, 实际获得_c / Need_c)
满意度        S*_c  = 50 + 60(s_c − e_c) − 20·税负_c + 10·政策_c + 10·信仰_c − 15·矛盾_c + 8·地位_c
              S_c  ← clamp( S_c + 0.35(S*_c − S_c) + ξ , 0, 100 )
组织度        O_c   = 0.3 + 0.5 × 设施加成 + 0.2 × 名人代言
政治分量      Pow_c = P_c × O_c × (1 + 财富集中度)
状态          服从(S>55) | 抱怨(30≤S≤55) | 反抗(S<30)
```

其中 `η(S) = 0.6 + 0.4 × S/100`（满意的人干活多），`e_c` 是阶级期望（见 §4.3），`ξ ~ N(0, 2)` 是年度波动。

**反抗升级（连续 2 年 S<30 才升一级，给玩家补救窗口）**：

| 级 | 表现 | 数值 |
|---|---|---|
| 1 怠工 | 产出下降 | 该阶级产出 −15% |
| 2 罢工/抗税 | 产出与税收双降 | 产出 −40%，该阶级税收 −50% |
| 3 暴动 | 城镇控制权倒计时 3 年 | 需镇压（军力）或让步（政策）；倒计时归零则城镇易主/独立 |

### 4.4 解锁链与「结构性阵痛」

解锁不是发福利，是**引入新矛盾**，玩家必须重新学一遍自己的国家：

| 解锁 | 触发 | 立刻带来什么麻烦 |
|---|---|---|
| 工人 | 建作坊 + 器需求 | 粮需求上升 → 粮价涨 → 农民受益、工人不满 |
| 商人 | 建市场 + 连通 | 行政定价失效 → 粮价波动放大；商人开始囤积 |
| 祭司 | 神庙 + 剩余 | 免税权与教义开始干预政策；与学者结怨 |
| 官僚 | 城镇中心 + 人口 8 | 俸禄开销；腐败开始出现；AP 才够用 |
| 学者 | 学宫 + 文字 | 研究要钱；学者要求审查豁免，与祭司/官僚冲突 |
| 军人 | 兵营 + 铁/马 | 军饷吃掉财政；军人政治分量上升，可能干政 |
| 文艺家 | 规模 20 + 剩余 30 | 奢侈品被大量消耗；艺术家批评朝政（满意度换声望） |

### 4.5 满意度与状态

见 §4.2 公式。UI 必须把 `S*` 的每一项拆开显示：`满足率 +6 / 税负 −1.6 / 政策 +2 / 信仰 +3 / 矛盾 −3 / 地位 0`。玩家要能立刻知道「这 3 点是谁扣的」。

**税负_c** = 实际税率 × 执行率（0–0.5）。**政策_c** 是政策向量对该阶级的加成（−1…+1）。**信仰_c** = 城镇信仰覆盖度 × 国教一致性。**矛盾_c** 见 §4.6。**地位_c** = 该阶级在朝堂/城镇议会中的代表权（−1…+1）。

### 4.6 阶级矛盾：4 条轴 + 6 组结构矛盾

不做 28 对两两关系。每个阶级算一个 0–1 的矛盾压力：

```
矛盾_c = 0.30 × 财富落差_c + 0.30 × (1 − s_c) + 0.20 × 税负_c + 0.20 × 权力落差_c
财富落差_c = clamp( (人均财富_全镇 − 人均财富_c) / 人均财富_全镇 , 0, 1 )
权力落差_c = 1 − 该阶级代表权
```

六组**结构性矛盾**（数据表，触发事件与效率惩罚）：

| 矛盾 | 载体 | 表现 |
|---|---|---|
| 农民 ↔ 商人 | 粮价 | 粮价高 → 农民富、工人/军人不满；粮价低 → 农民破产 |
| 农民 ↔ 官僚 | 税役 | 加税 → 农民反抗；减税 → 国库空 |
| 工人 ↔ 商人 | 工价/物价 | 商人压价 → 工人失业；工人要价 → 利润崩 |
| 官僚 ↔ 商人 | 专卖/自由 | 专卖增收但商人外逃；自由则财政漏 |
| 祭司 ↔ 学者 | 信仰/理性 | 理性上升 → 香火下降；虔诚上升 → 研究变慢 |
| 军人 ↔ 文艺家 | 尚武/文治 | 军费挤占艺术赞助；文艺批评削弱军队威望 |

**政策 = 向量**（这是全作最重要的可玩性接口）：

```jsonc
{ "id": "policy.flat_sale", "name": "平粜", "ap": 3, "cost": { "silver": 120 },
  "gains": [["class.worker", +8], ["class.soldier", +6]],
  "losses": [["class.farmer", -10], ["class.merchant", -12]],
  "effects": [{ "price.food": -0.20 }, { "stock.food": -40 }] }
```

玩家每个决策都在「让谁不舒服」，系统只多一张表。

### 4.7 人口：增长、转化、迁移

```
增长   ΔP = P × (0.04 × 粮安 − 0.03 × 拥挤 − 0.02 × 疫病 + 0.01 × 医疗)   // 粮安∈[0,1.2]
拥挤   = max(0, 总人口 / 住房容量 − 1)
转化   每年单阶级转入 ≤ 总人口 2%，按「阶级吸引力」差额分配
吸引力 = 收入 + 就业 + 地位 + 福利 − 生活成本 − 风险
迁移   两镇效用差 = (实发工资 − 物价) + (满意度 − 50)/5 − 通行成本；正差则流
```

人口是**会投票的流体**：地价、税负、粮价会立刻变成迁移。迁移也意味着「你把工人逼走，隔壁城白捡人口」。

### 4.9 一个算例（实现者拿它当第一个单测）

白石城 12 人口单位：农 6、工 2、商 1、官 1、祭 1、学 1。辖地粮潜力合计 18，料潜力合计 2。

- 粮产出 = min(6 × 2.4 × 1.0 × η(50)=0.8, 18 × 1.0) = min(11.52, 18) = **11.52**
- 粮需求 = 12 × 1.0 = **12** → 缺口 0.48，价按公式二上涨
- 料产出 = min(6 × 0.9 × 0.8 = 4.32, 2 × 1.0) = **2.0**；工人要 2.4 → 缺料 17%，器产出 ×0.83
- 器产出 = 2 × 1.2 × 0.8 × 0.83 = **1.59**
- 农民满足率 = 11.52/12 = 0.96 → `S* = 50 + 60(0.96−0.85) − 20×0.08 ≈ 55`，`S ← 50 + 0.35×5 = 51.8`
- 结论：**「地够粮不够、粮够料不够」的小镇会自然进入涨价—缺料—满意度下滑的循环**，玩家必须补农田、开矿场或开商路。这就是核心玩法的最小闭环。

## 5. 经济系统

### 5.1 五种物资 + 一套货币

| 物资 | id | 说明 | 基准价（银） |
|---|---|---|---:|
| 粮 | `good.food` | 全员生存刚需；价格最敏感 | 4 |
| 料 | `good.mat` | 木/石/矿/陶合并 | 3 |
| 器 | `good.goods` | 工具/布/建材/兵器/书籍合并 | 8 |
| 奢 | `good.lux` | 奢侈品，满意度与文化燃料 | 20 |
| 银 | `good.silver` | 货币，也是国际唯一结算手段 | 1（计价单位） |

**非物资资源**（不进库存交易，只做状态量）：知识 `tech`、信仰 `faith`、文化 `culture`、政令 `ap`、声望 `prestige`。

> 为什么只有 5 种：物资每多一种，价格求解器、AI 决策、UI、平衡表都要乘一次；5 种已经能撑起「农业—工业—奢侈—贸易」的完整结构。科技只改**品质系数**，不新增品类。
>
> **银不参与价格求解**，它是计价单位（numeraire）：公式二只跑粮/料/器/奢四种；银的「价格」由通胀因子 κ 体现。

### 5.2 公式一：转化（生产）

```
产出 = min( P × λ × Tech × η(S) , Cap × Facility )
Facility = 1 + 0.15 × 产业设施等级（上限 1.45）
投入 = 产出 × 投入系数            // 器 需要 料；奢 需要 器 + 料
缺料折扣 = min(1, 可用料 / 所需料)
实际产出 = 产出 × 缺料折扣
```

- `Tech` 是该类技术的倍率（1.0–2.5），来自科技卡。
- `Cap` 是辖地潜力（§3.6）。**地是硬上限，人是软上限**——这是扩张动机。
- 投入系数：器 每单位耗 1.0 料；奢 每单位耗 1.5 器 + 1.0 料。

### 5.3 公式二：价格（一个求解器，三种开放度）

```
p_{t+1} = clamp( p_t × (1 + α × (D_t − S_t) / max(S_t, 0.5) + shock_t) , 0.2 × p0 × κ , 5 × p0 × κ )

κ = clamp( (M_global / M_ref)^0.4 , 0.7 , 2.5 )     // 货币因子（通胀）
```

| 循环 | α | 库存主体 | 玩家手段 |
|---|---:|---|---|
| 城镇内 | 0.30 | 镇仓 | 限价、配给、平粜、徭役 |
| 国内 | 0.15 | 镇仓 + 国库 | 税率、专卖、国债、铸币、道路投资 |
| 国际 | 0.08 | 各国国库 | 关税、禁运、补贴、条约 |

- `D` 本期需求，`S` 本期可售（产量 + 库存 + 进口）。
- `shock`：本地 N(0, 0.04)（天气/灾害），国内/国际为 0。
- 上下限 `0.2×p0×κ ~ 5×p0×κ` 防止价格爆零或飞天；`κ` 让「白银流入 → 物价上涨」可计算。
- **国内价格不是凭空的国家价**，而是各镇价格按运输成本加权；修一条路，两个镇就真变成一个市场。

### 5.4 城镇内循环（钱和货怎么转）

每回合按顺序：

1. **生产**：农/工按公式一出货，进镇仓。
2. **需求**：各阶级按需求篮子 × 人口报需求；手里没银子的需求是「无效需求」。
3. **出清**：按公式二定价，从高价需求者开始撮合，直到售罄或需求清空。
4. **收入**：生产者得到货款；商人抽 10% 撮合佣金；国库按税率抽税；祭司收香火钱（城镇产出的 5%，直接从各阶级收入划转）；官僚/军人/学者/文艺家吃国库俸禄与预算（§5.5），欠俸即掉满意度。
5. **短缺**：未满足比例直接进 `s_c`，次年满意度下降。
6. **库存**：剩余物资留仓（粮有 5%/年损耗，需粮仓建筑降低）。

> 关键设计：**内循环不追求平衡**。放任工业扩张必然导致「工人多 → 粮紧 → 粮价涨 → 农民扩产 → 工人买不起 → 罢工」。玩家的工作是决定这轮让谁吃亏。

### 5.5 国内循环（城际贸易 + 国家财政）

**城际贸易**由商人自动执行，玩家只设规则：

```
套利条件： (p_B − p_A) > 运输成本 + 关税 + 风险溢价
运输成本 = 0.02 × 路径格数 × 地形系数 × (水运 ? 0.4 : 1) × (1 + 0.3 × 战乱)
成交价 = (p_A + p_B) / 2，商人赚差价，两镇价格被拉平
```

**国家财政**：

| 收入 | 计算 |
|---|---|
| 土地税 | Σ 农业产出价值 × 农税率（默认 20%） |
| 商业税 | Σ 城镇交易额 × 商税率（默认 12%） |
| 关税 | 进出口额 × 关税率（默认 10%，可 0–100%） |
| 专卖 | 盐/铁/酒：产量 × 专卖出厂价 − 成本（利润率高，商人满意度 −） |
| 贡赋 | 附庸国按其产出 10–20% |
| 铸币息 | 铸币量 × 成色差额（**制造通胀**） |
| 抄没 | 抄家名人 / 没收商人资产（一次性，政治代价高） |

| 支出 | 说明 |
|---|---|
| 官俸 | 官僚人口 × 10 银/年（欠薪 → 执行率崩） |
| 军饷 | 军人人口 × 12 银/年 + 装备采购 |
| 基建 | 建筑造价的 20%/年维护 |
| 平准 | 平粜/收储的粮款 |
| 补贴 | 指定城镇/阶级的转移支付 |
| 偿债 | 国债本息 |

**赤字处理**：可向商人阶级发债（利率 8–15%/年），或铸币（通胀 κ↑），或欠薪（满意度崩）。三条路都有代价，这是「国库是全局压力锅」的实现。

### 5.6 国际循环（外贸、倾销、白银）

- 只有**边境/港口城镇**、且有通商条约，才能跨国交易。
- 关税由进口国设；禁运 = 关税率 100%；走私 = 有 30–60% 概率绕过关税（被查获则关系 −10）。
- **倾销**：若 A 国器价远低于 B 国，商人大举出货 → B 国器价暴跌 → B 国工人收入崩 → B 国工人满意度崩 → B 国玩家被迫加关税或开战。**这是不花军费的进攻。**
- **白银传导链**：出口顺差 → 银流入 → `M_global`↑ → κ↑ → 物价普涨 → 吃固定俸禄的官僚/军人不满意上升 → 必须调俸或加税 → 政治压力。四行逻辑，一个很「近代早期」的现象。

### 5.7 数值基线（标定起点）

| 参数 | 值 |
|---|---|
| 粮/料/器/奢 基准价 | 4 / 3 / 8 / 20 |
| 农税率 / 商税率 / 关税率 | 20% / 12% / 10% |
| 官俸 / 军饷 | 10 / 12 银/人/年 |
| 粮仓损耗 | 5%/年（粮仓 −2%/级） |
| 运输成本 | 0.02 银/格/单位 |
| 商人佣金 | 10% |
| 国债利率 | 8% + 信用风险 0–7% |
| 破产阈值 | 国库 < 0 且连续 2 年 → 信用崩、欠薪、商人拒贷 |

### 5.8 默认演化剧本（验收用）

固定种子、AI 全放任、玩家不干预，应稳定出现：

1. 前 20 年：农业剩余 → 人口增长 → 手工业出现；
2. 20–60 年：工人激增 → 粮价上涨 30–80% → 农民短暂繁荣；
3. 60–100 年：商人囤粮 + 行政定价失效 → 城市粮价暴涨 → 工人/军人反抗 → 暴动或政策转向；
4. 若玩家一直不管：某城独立或被邻国吞并。

**如果模拟跑不出这个剧本，说明经济标定错了**，不是剧本错了。

### 5.9 不变量（每阶段末校验，违反即报错）

- 物资守恒：`期初 + 产出 + 进口 − 消费 − 出口 − 损耗 = 期末`（误差 < 0.01）。
- 银守恒：仅铸币、外贸、抄没可改变总量，且每次变动必须有来源记录。
- 人口守恒：Σ 阶级人口 = 城镇总人口；迁移前后全局守恒。
- 价格区间：`0.2×p0×κ ≤ p ≤ 5×p0×κ`。
- AP：已用 ≤ 容量 × 1.5（超容打折，但不许无限超）。
- 状态机：阶级状态不可跳级（服从 → 抱怨 → 反抗 → 暴动）。

### 6.2 城镇归属：四态 + 占领，用系数不用四套规则

| 归属 | 税抽取 | 征兵 | 政策强度 | 独立倾向 | 特点 |
|---|---:|---|---:|---:|---|
| 直属 `core` | 100% | 是 | 1.0 | 低 | AP 消耗高，需官僚 |
| 属地 `province` | 75% | 是 | 0.8 | 中 | 常规扩张结果 |
| 自治 `autonomous` | 55% | 有限 | 0.6 | 中高 | 地方强宗，满意度高、叛离风险高 |
| 附庸 `vassal` | 35% + 贡 | 否 | 0.4 | 高 | 缓冲国，朝贡收入 |
| 占领 `occupied` | 30% | 否 | 0.3 | 极高 | 需 5–10 年整合，否则叛乱 |
| 独立 `independent` | 0 | 0 | 0 | — | 中立市场、走私通道、文化归附靶子 |

**分离倾向**（每年，`sep` 0–1）：
```
sep += 0.02 + 0.03×(1 − 平均满意度/100) + 0.02×距离 + 0.02×文化差 − 0.02×驻军 − 0.01×补贴
sep ≥ 1 → 宣布独立或投靠邻国
```

### 6.3 AP：行政瓶颈（本作最重要的限制器）

```
AP_容量 = Σ_城镇 ( 官僚P × 2 × (1 − 腐败) ) × 中央权威
政策/建设/外交/军事指令消耗 1–5 AP
超容：不打折禁止，而是「执行率 ×(容量/需求)」→ 帝国越大，越管不动
```

这条规则同时解释了三件事：为什么大帝国会散、为什么反腐会得罪整个官僚层、为什么玩家要抢着养官僚。

### 6.4 财政

见 §5.5。预算盘（§6.1 `budget`）五个滑块，总和 100%；每项不足时对应系统直接降效（欠俸 → 执行率、欠饷 → 士气、欠科研 → 知识、欠文化 → 声望、欠赈济 → 灾年暴动）。

### 6.5 政治：四方权力 + 派系

不做 7 种政体硬编码。国家权力由四个 `Pow` 构成：

| 权力方 | Pow 来源 | 想要什么 |
|---|---|---|
| 王权 | 合法性、军队忠诚、血统 | 集权、战争、宏大工程 |
| 官僚 | 官僚人口 × 行政效率 | 编制、预算、审批权 |
| 地方 | 城镇自治度 × 商人/地主财富 | 低税、自治、贸易自由 |
| 院 | 祭司 + 学者 + 文艺家 | 教义、审查、赞助 |

- **政体是涌现标签**：谁 `Pow × 忠诚` 最高，谁定继承与决策规则。`gov` 字段只是数据预设（部落议事/贵族共治/官僚君主/商业共和），改变的是「任命方式、税收权限、代表权、政策成本」，不是另写规则。共和/议会政体下，部分槽位必须由廷议选举（玩家提名、按 Pow 表决），不能直接任命——这就是 README 所说「国家可以选举名人」。
- **派系**：各阶级 + 名人关系网自动结党（重商派/军国派/清流/教派）。派系 `power` 影响政策通过率；强行推行 → 朝堂动荡（合法性 −、地方自治 +）。
- **廷议**：每 5 年一次，按 Pow 加权表决一个政策包；玩家可否决，但付合法性代价。

### 6.6 宗教（祭司）

信仰不是 buff 集合，是**满意度阈值下移器**：

- 有国教：反抗阈值 30 → 25；缺粮时祭司可「施粥/讲经」临时压制暴动（花信仰，不花银）。
- 传播：`速度 = 祭司数 × 神庙 × 距离衰减 × (1 − 抵抗)`；沿商路自动渗透。
- 三条路线：**国教压制**（快，埋分裂） / **多教并存**（稳，效果弱） / **世俗化**（释出庙产与祭司 Pow，换学者+商人加成，宗教福利消失）。
- **教义卡**：消耗信仰抽 3 选 1（例：苦修主义：日用品消耗 −20%；圣战狂热：对异教 +25% 攻击；宽容令：异端冲突 −50%）。教义是全局规则修改，稀有度同名人。

### 6.7 科技（学者主，祭司辅）

- 产出：`知识 = 学者P × 供养系数 × 机构 × (1 + 教化加成)`；祭司的「历法/文字」提供**前置解锁**与教化加成，因此祭司仍在科技线上，但不是主产出。
- **卡池制，不是固定树**：攒满科研槽 → 从当前时代卡池抽 **3 张**，选 1。
  `科研槽 = 12 × (1 + 0.25 × 已解锁卡数)`（1 名学者约 4 年出第一张卡，50 张卡撑满 200 年）。未被选的卡回池，下次仍可能出现。
- 六条分支：农业 / 工业 / 商业 / 行政 / 军事 / 文化，各 8–10 张卡，共约 50 张。
- 科技的效果只有两种：**改公式参数**（倍率、α、上限）或**解锁 hook 条件**（建筑、兵种、政策）。**不引入新机制。**
- 关键节点：堤坝（三角洲安全）、犁与轮作（粮 ×1.2）、文字历法（祭司→教化）、印刷（学者+文艺家）、冶炼/马镫（兵种门控）、复式记账（商人资本上限）、船坞（海军）、纸钞（可控通胀）、火器（攻城与隘口价值重估）。
- **技术外流**：学者/名人叛逃会带走技术（对方获得该卡）。

### 6.8 军事（军人）

**兵种只有 8 个模板**，靠「装备等级 × 地形许可」区分，不做 30 种兵：

| 兵种 | 需求 | 特点 |
|---|---|---|
| 民兵 | 无 | 便宜、守城、士气低 |
| 轻步 | 无 | 便宜、机动 |
| 重步 | 铁 | 正面强、慢 |
| 弓 | 料 | 远程、怕骑 |
| 骑 | 马 | 高机动、冲阵 |
| 甲骑 | 马+铁 | 决战单位、贵 |
| 攻城 | 料+铁 | 攻城、野战弱 |
| 战船 | 港口 | 海运、封锁 |

**补给线**是地形价值的兑现点：

```
补给能力 = 通往本国城镇的路径最低容量 × 距离衰减 (1 − 0.05 × 格数)
断线：士气 −15%/回合，2 回合后开始溃散（兵力 −10%/回合）
```

**战斗**（自动解算，无战术棋盘）：

```
战力 = 兵员 × 装备(0.6–1.6) × 训练(0.6–1.4) × 士气(0.3–1.2)
      × (1 + D/100) × 将领(0.8–1.5) × 随机(0.85–1.15)
```

以**士气崩溃**判定败北，不做全歼；败方退入工事可重整。伤亡：败方 20–35%，胜方 10–20%。

**战争目标**：占领城镇、封锁隘口/河口、断水、掠夺、附庸化、占领首都。占领后进入 `occupied` 状态，需整合。

### 6.9 文化（文艺家主，军人可赞助）

```
文化产出 = 文艺家P × λ × 设施 × 赞助系数
声望 = 累积文化 × (1 − 审查) × (1 + 名作加成)
```

文化值三处生效：

1. **独立城镇归附**：`P(归附/年) = clamp(0.02 + 0.05×文化差 + 0.03×满意度差 + 0.03×贸易联系 − 0.04×军力威慑, 0, 0.4)`。
2. **附庸忠诚**：文化辐射提高忠诚，降低 `sep`。
3. **他国软进攻**：文化输入提高对方城镇不满（不花一分军费）。

**名作**：灵感值满（15 文化）→ 抽 1 张（稀有度：习作/佳作/名篇/传世），提供全局 buff 与声望。军人赞助可产出「尚武文化」，军事 +，但文艺家满意度 −。

### 6.10 外交

- 关系值 −100…100，由贸易、边境摩擦、意识形态、历史恩怨、名人事件驱动。
- 条约：通商、通行权、互不侵犯、防御同盟、军事同盟、科技交流、朝贡、赔款、领土谈判。
- **宣战理由**（无理由宣战 → 全体关系 −15、国内合法性 −10）：边境争端、断水、禁运、保护附庸、宗教冲突。
- **间谍**：偷科技、煽动阶级矛盾（对方某城满意度 −10）、收买名人（对方名人忠诚 −20，可能叛逃）。
- **独立城镇也是外交主体**：可通商、游说、册封、征服、文化归附。

### 6.11 国家 → 城镇的七条作用链（README「国家与城镇交互」的落点）

国家不直接改城镇数字，只通过七根杠杆施压；每根杠杆都会落到具体阶级身上：

| 杠杆 | 作用机制 | 直接受力者 |
|---|---|---|
| 税 | `实收 = 税基 × 税率 × 执行率 × 归属系数`；欠税转为阶级怨气 | 农民（地税）、商人（商税） |
| 政策向量 | 每项政策带 gains/losses，按 §4.6 改满意度 | 全部阶级 |
| 征兵 | 抽走农民/工人人口，家庭满意度 − | 农民、工人 |
| 补贴/平粜 | 国库 → 指定城镇/物资，短期压价或救急 | 工人、军人（受益）；商人（受损） |
| 任命 | 官员能力/忠诚/关系 → 执行率（§7.5） | 全系统效率 |
| 建设 | 国家出资建城/修路/关城，改变 C、D 与 AP 成本 | 沿线城镇 |
| 文化/宗教 | 声望与信仰覆盖 → 满意度与归附概率 | 祭司、文艺家、边缘城镇 |

**逆向通道**同样存在：城镇的阶级满意度 → 国家稳定度/合法性；城镇上缴 → 国库；城镇自治度 → 分离倾向；名人出身城镇 → 卡池质量。**国家不是上帝视角，它也被城镇反噬。**

## 7. 名人系统（抽卡主引擎）

名人系统是把政治、军事、经济、文化串成**一个实体**的枢纽，也是本作「抽卡快乐」的主来源。

### 7.1 数据结构

```jsonc
{
  "id": "hero.0042",
  "name": "沈砚",
  "class": "class.merchant",                 // 出身阶级 = 立场
  "rarity": "epic",                          // common/fine/epic/legend
  "stats": { "admin": 58, "scheme": 91, "war": 22, "fame": 64 },
  "traits": ["trait.silver_tongue", "trait.greedy"],
  "skill": "skill.market_oracle",
  "loyalty": 62, "ambition": 71, "fatigue": 0,
  "relations": [{ "to": "hero.0031", "value": -60, "type": "rival" }],
  "office": "town.0007.governor",            // 或 null（在野）
  "wealth": 340                               // 贪污积累，可被抄没
}
```

**四维，不是六维**：理政 `admin`（行政/财政）、筹策 `scheme`（经济/科技/外交）、军功 `war`（作战/统军）、声望 `fame`（文化/宗教/民心）。四维足够区分角色，六维只是配点噪音。

### 7.2 特质与技能：负面特质必须改变结算

| 正面特质 | 负面特质 |
|---|---|
| **能臣**：执行折扣归零 | **巨贪**：每年私吞 15% 税收，但理政 +10 |
| **清廉**：全国腐败 −0.05 | **刚愎**：战场拒绝撤退，溃败时伤亡 ×1.5 |
| **屯田**：所在城镇军粮自给 +30% | **骄横**：与同僚关系每年 −10，易结党 |
| **通商**：外贸 α +0.03 | **阶级死忠**：牺牲他阶级时满意度额外 −8 |
| **儒将**：行军不扰民（占领 `riot` −30%） | **篡逆**：野心 +20，掌兵后有政变倾向 |
| **点石成金**（传奇专属）：所在城镇料按 300% 价折银 | **清流**：全国腐败 −，但所有官僚 −10 满意度 |

规则：普通 1 正 0 负；优秀 1 正 + 35% 概率 1 负；杰出 1 正 + 70% 概率 1 负；传奇 1 正 + 1 负（必然）+ 专属技能。

### 7.3 稀有度、概率与保底

| 稀有度 | 主维区间 | 基础权重 | 技能数 |
|---|---|---:|---:|
| 普通 | 48–75 | 55% | 0–1 |
| 优秀 | 54–81 | 30% | 1 |
| 杰出 | 60–87 | 12% | 2 |
| 传奇 | 66–95 | 3% | 2 + 专属 |

- **先按权重定稀有度，再掷点**：主维 `45 + 3d10 + 加成(0/6/12/18)`，副维 `30 + 2d10 + 加成/2`，其余 `20 + 2d10`，全部截断 5–95。这样「传奇」不会因为掷点运气而名不副实，属性区间也可直接用于平衡表。
- 出身阶级决定主维与技能池（商人→筹策，军人→军功，学者→筹策/声望，祭司→声望，官僚→理政）。
- 稀有度不决定「有没有用」，只决定「上限与副作用」：传奇必带负面特质（§7.2）。
- **保底**：连续 9 次未出杰出及以上，第 10 次强制杰出+；保底计数存于存档，联机同步。
- **所有概率可查**：UI 必须展示当前卡池权重与保底进度（README 的「抽卡快乐」不等于黑箱）。
- **低稀有度不是废物**：普通名人也能当县令/税吏，且培养后（任期、功绩）可升维。

### 7.4 抽卡循环：从城镇里长出来的人

```
每城镇每阶级每年产生候选概率 = P_c × 0.004 × (1 + 相关建筑等级 × 0.2) × (1 + 声望/200)
全国在野池上限 8 人；池内人物 5 年未被征辟则离开（可能投奔他国）
征辟（抽卡）：3 选 1，消耗 2 AP + 30 银 × (1 + 已招募数 × 0.2)
卡池受国策影响：崇文 → 学者/文艺家权重 ×1.5；穷兵 → 军人 ×1.5；重商 → 商人 ×1.5
```

**结果要「落到某个 slot」**：抽到「屯田」军人，界面直接提示「边镇军粮自给 +30%，现在可以在北境建城」。随机与规划相连，而不是纯数值惊喜。

### 7.5 任命与「上令不一定下达」

可任命槽位：宰相、户部（经济）、兵部（军事）、礼部（科教文卫）、外交、城镇太守、军团统帅。岗位能力要求：太守 50 / 户部 60 / 兵部 65 / 外交 55 / 礼部 55 / 宰相 70。

```
执行率 = clamp(0.4 + 0.6 × min(1, 能力/岗位要求), 0, 1)
        × (0.6 + 0.4 × 忠诚/100)
        × 关系系数          // 政敌受益 0.7；同党 1.15；其余 1.0
        × 中央权威          // 0.5–1.2
```

**必须显示执行链**（这是本作 UI 的招牌）：

> 加征商税：基础 100 → 能力不足 −18% → 与商人领袖是姻亲 −30% → 中央权威 0.8 ×0.8 → **实收 46**，太守上书反对，商人满意度 −12。

玩家的真实决策由此产生：把政敌派去执行他反对的政策，代价是什么？

### 7.6 诉求、人际、叛逃、政变、抄家

- **诉求**：每 3–6 年一次（要权/要钱/要免税/要整倒某人/要联姻）。满足 → 忠诚 +、能力释放；拒绝 → 消极、结党、投奔他国（带走科技）、政变。
- **人际网**：关系 −100…100，类型：师生/姻亲/同党/政敌。罢免一人，其同党忠诚 −10，政敌 +10。
- **叛逃**：忠诚 < 20 且与君主关系 < −50 → 有概率投敌（带走其掌握的科技与 1 张名人卡）。
- **政变**：`野心 ≥ 75 && 忠诚 ≤ 30 && 掌兵 && 权威 < 0.7` → 每年 5% 检定；成功则独立或篡位。
- **贪官养肥再杀**：贪官每年把 `15% 税收` 记入 `wealth`；玩家可「政治清算」一次性没收 `0.8 × wealth`，但同党派系 −10 忠诚、官僚 −5 满意度。这是本作最爽的一类操作。

### 7.7 名人强度护栏（防止「一张卡通关」）

1. 名人的加成**全部乘在公式上，不替换公式**；上限：单系统 +40%，全局 +15%。
2. 每个名人同时只能任 1 职；离任后加成 3 年内衰减。
3. 强名人必然配强负面或高野心（§7.3 概率表）；传奇必带负面。
4. 名人不能直接给你资源，只能改变**效率与规则**；资源仍要走生产和贸易。
5. AI 与玩家用同一套名人规则，AI 不作弊。

## 8. 随机性与事件

### 8.1 六类卡池

| 卡池 | 触发 | 玩家选择 | 随机内容 | 保底 |
|---|---|---|---|---|
| **人物寻访** | 城镇产出 + 征辟令 | 3 选 1 | 四维、阶级、特质、技能、关系 | 10 次必出杰出+ |
| **科技灵感** | 知识攒满科研槽 | 3 选 1 | 六分支、时代、稀有度 | 每 5 次必出未拥有卡 |
| **事件抉择** | 条件触发 | 2–3 个选项 | 天灾、商机、宗教争议、阶级冲突 | 无（条件驱动） |
| **艺术名作** | 灵感值攒满 15 文化 | 抽 1 张 | 习作/佳作/名篇/传世 | 每 10 件必出传世 |
| **地貌发现** | 探索/建城/战斗 | 3 选 1 词条 | 矿脉、良田、山口、独立城镇 | 无 |
| **教义卡** | 信仰攒满 20 | 3 选 1 | 教义与全局规则修改 | 10 次必出稀有 |

**统一规则**：每张卡都有 `rarity`、`weight`、`pityGroup`；抽卡结果写入命令日志，可回放、可校验。

### 8.2 事件：只写表，不写代码

```jsonc
{
  "id": "event.grain_crisis",
  "trigger": { "town.food_shortage_years": { "gte": 2 }, "weight": 40 },
  "text": "北境连续两年歉收，城中粮价已涨至三倍。",
  "options": [
    { "id": "opt.flat_sale", "ap": 2, "cost": { "silver": 150 },
      "effect": { "price.food": -0.25, "sat.worker": +6, "sat.merchant": -10 } },
    { "id": "opt.ration", "ap": 1,
      "effect": { "sat.worker": +3, "sat.farmer": -6, "riot": +0.1 } },
    { "id": "opt.ignore", "effect": { "sat.worker": -12, "riot": +0.25 } }
  ]
}
```

**设计约束**：每个事件必须至少影响 **两个阶级的满意度** 或 **一种物资价格**，否则没有决策价值，不写。

事件类型：天灾（洪水/蝗灾/瘟疫/地震）、丰收、继承危机、名臣降临、大罢工、行会请愿、学宫辩论、异端运动、边患、新资源/新形胜发现、他国使团、商队被劫（生成外交事件）。

### 8.3 分层确定性随机（联机、回放、调参的共同地基）

```
seed(worldSeed, namespace) = SplitMix64(worldSeed ⊕ hash(entityId) ⊕ hash(namespace))

namespace 示例："hero.roll.town12.turn57"、"battle.unit332.turn88"、"event.draw.nation3.turn12"
```

规则：

1. 每个随机点独立命名空间，不共享流；
2. 遍历顺序固定（按 id 升序，禁止依赖字典枚举顺序）；
3. 存档保存 RNG 状态；
4. 同种子 + 同命令流 ⇒ **位级相同**状态；
5. 抽卡保底与权重可在单测里精确验证（例：10 万次统计「10 连必出杰出」）。

### 8.4 可解释性（README「让玩家理解发生了什么事」的落点）

任何结算都要能展开成三段：

```
结果：白石城粮价 +18%
公式：p' = clamp(p × (1 + 0.30 × (D−S)/max(S,0.5)), ...)
各项：D 12.4（+军队征粮 1.2） / S 10.5（−北境干旱 22%） / κ 1.04
```

实现方式：所有状态修改走 `ctx.Mutate(path, delta, reason)`，Core 记录 diff 与 reason，UI 直接渲染成因果链。

## 9. 联机与 AI

### 9.1 三种模式，一套模拟

| 模式 | 说明 |
|---|---|
| 单人 | 1 玩家 + N AI 国家 |
| 本地热座 | 多人轮流提交，统一结算；可隐藏他人私有信息 |
| 在线 | 2–8 人，房主权威，Steam 邀请/房间；断线重连、AI 托管 |

### 9.2 权威主机 + 命令流

- 主机（或专用服务器）跑唯一一份 sim；客户端只提交命令与渲染。
- 只同步：命令、回合号、公开状态、状态哈希、低频快照。**不同步画面对象。**
- 同时回合：各玩家提交后进入「等待」，全部提交或倒计时结束即结算；未提交者由 AI 托管。
- 客户端不能指定自己的金钱/人口/战斗结果；主机校验命令合法性（身份、回合、资源、目标、规则）。

### 9.3 校验与容错

- 每回合末广播**分块状态哈希**；不一致 → 客户端上传命令流 → 服务端回放定位到出问题的回合。
- 断线：重连拉快照 + 增量命令；离线玩家由 AI 托管，回来无缝接回。
- 反作弊靠「确定性 + 权威 sim」，不靠客户端可信。

### 9.4 AI：一套决策函数，服务三种场景

**这是全项目最大的一处逻辑复用**：AI 国家、名人自动决策、断线托管，用同一个 `DecisionAgent` 接口，只是「授权范围」不同。

| 层 | 决策内容 |
|---|---|
| 1 国家战略 | 定性格权重（扩张/商业/文化/科技/防御/宗教/平衡）与长期目标 |
| 2 城镇发展 | 建什么、升级什么、人口往哪引 |
| 3 财政 | 税率、预算盘、借债、铸币 |
| 4 外交军事 | 结盟、宣战、行军、补给 |
| 5 人事 | 征辟、任命、满足/拒绝诉求 |

- AI 与玩家使用**同一套命令接口**，不给额外资源、不改结算结果。
- AI 每年检查：粮是否够、市场是否短缺、财政是否赤字、是否失业、矛盾是否严重、是否该建城、有没有值得抽的人。
- 官员自主决策 = 受限的 Agent：只能用自己职位的命令集，且受执行率公式约束。

## 10. 技术架构

### 10.1 引擎与语言（ADR-001/002）

**选定：Godot 4.x Stable + C#（.NET 8）。模拟内核 `SimCore` 为独立 .NET 类库，不引用任何 Godot 类型。**

| 候选 | 优点 | 代价 | 结论 |
|---|---|---|---|
| **Godot 4 + C# + SimCore** | MIT、原生 Steam、hex/TileMap 够用；SimCore 可 `dotnet test` 无头跑，不装引擎也能开发与标定 | 需自建 hex 数学库（约 300 行）；C# 与 Godot 绑定需注意版本 | **选它** |
| Godot 4 + GDScript | 上手最快、AI 熟悉 | 无静态类型约束、大规模模拟与 CI 测试弱、平衡脚本难跑 | 仅用于 UI 胶水，不作主体 |
| TypeScript + Pixi + Electron | UI 迭代快、单测轻 | 包体大、性能吃紧、无专用服务器生态 | 备选：若 Godot 壳层受阻，SimCore 可原样换宿主 |

**纪律**：`SimCore` 只能依赖 `System.*`。渲染层通过事件订阅读取状态，**永远不在 UI 里写规则**。这条纪律让「换引擎」「跑无头模拟」「做平衡机器人」都只花一次工。

### 10.2 Core 的职责（ADR-003）

Core 不认识「农民」「粮食」「宗教」。它只有九件事：

1. **世界存储**：`World { id → Entity }`，实体持纯数据组件；不做完整 ECS（字典 + 组件 + 类型化访问器足够）。
2. **阶段调度器**：§2.3 的固定顺序与 hook 顺序。
3. **确定性随机**：§8.3 分层 RNG。
4. **数据注册表**：JSON 数据包、`def:` 引用解析、schema 校验。
5. **命令总线**：所有状态变更必须经命令；记录日志供回放。
6. **不变量守卫**：§5.9 的守恒与区间断言，每阶段末校验，违反即报错（不是静默扩散）。
7. **存档 / 回放 / 迁移**：快照 + 命令日志 + 版本迁移链。
8. **插件宿主**：加载、依赖排序、启用/禁用、API 版本检查。
9. **同步层**：单机为本地环回，联机换传输，**sim 代码零改动**。

**Core 不含**：地形规则、阶级、经济、科技、宗教、军事、名人生成、外交、AI 决策。

**`core.basic` 参考规则包**（内置，可关）：平原/山地两种地块、农民、粮食、建城、回合、存档。它既是「Core 可独立运行」的证据，也是插件接口的活体契约测试。

### 10.6 存档、迁移、回放

```
save = schemaVersion + gameVersion + worldSeed + snapshot(zstd) + commandLog + pluginVersions + rngState
replay = snapshot + commands
```

- 每次结算后快照；重要行动前留恢复点；存档失败不得覆盖最后一个有效存档。
- **改数据结构必须附迁移器 + 旧档回归测试**，否则不许合入；提交信息打 `[破存档→已附迁移器]`。
- 加载时逐城镇做守恒校验，失败要报「哪一项、差多少」。

### 10.7 确定性规则

- 禁止 `Dictionary` 枚举顺序影响结果（统一按 id 排序）。
- 禁止 `float` 参与需要位级一致的比较；关键量用 `int` 定点（银 ×100，物资 ×100）。
- 禁止在 sim 里读 `DateTime.Now`、随机设备、系统语言。
- 时间、随机、路径查找全部经注入的 provider。

### 10.8 测试与标定（AI 开发的生命线）

| 类型 | 内容 |
|---|---|
| 单测 | 三条公式各自可测，不启动渲染 |
| 不变量 | 物资/人口/银守恒、价格区间、状态机不越级 |
| 确定性 | 同种子同命令流 → 状态哈希一致 |
| 存档 | save → load → replay 同命令流 → 哈希一致 |
| 平衡 | 固定种子跑 20 国 120 年，检查是否有单一策略胜率 > 55% |
| 性能 | 500 城镇 × 200 回合无头时间剖面，目标 < 60 秒 |
| 抽卡 | 10 万次统计验证稀有度与保底 |

CLI：`sim run --seed X --turns N --headless --out report.csv`。**每个里程碑提交必须附一份基线模拟报告。**

## 14. 风险与预案

| 风险 | 表现 | 预案 | 触发阈值 |
|---|---|---|---|
| **复杂度失控** | 系统越写越多，谁也算不清 | 三条公式铁律；写不进「公式 + 耦合表一行」的功能不做；每里程碑清点逻辑量 | 单里程碑规则条目 +30% 即复盘 |

## 附录 A：公式速查（写代码时贴着看）

```
# 1 生产
Out  = min( P × λ × Tech × η(S) , Cap × Facility )
Facility = 1 + 0.15 × 产业设施等级（≤1.45）
η(S) = 0.6 + 0.4 × S / 100
实际 = Out × min(1, 可用原料 / 所需原料)

# 2 价格
p' = clamp( p × (1 + α × (D − S) / max(S, 0.5) + shock) , 0.2·p0·κ , 5·p0·κ )
κ  = clamp( (M / M_ref)^0.4 , 0.7 , 2.5 )
α  = 0.30(镇内) / 0.15(国内) / 0.08(国际)

# 3 满意
S* = 50 + 60(s − e) − 20·税负 + 10·政策 + 10·信仰 − 15·矛盾 + 8·地位
S  = clamp( S + 0.35(S* − S) + ξ , 0 , 100 )        ξ ~ N(0,2)
状态：>55 服从 / 30–55 抱怨 / <30 反抗（连续 2 年才升级）

# 4 阶级矛盾
矛盾 = 0.30·财富落差 + 0.30·(1 − s) + 0.20·税负 + 0.20·权力落差

# 5 行政
AP容量 = Σ( 官僚P × 2 × (1 − 腐败) ) × 中央权威
执行率 = clamp(0.5 + 0.25·官僚充足 + 0.15·清廉 + 0.1·道路, 0.1, 1.0)
实收税 = 税基 × 税率 × 执行率 × (1 − 0.5·腐败)

# 6 名人执行
执行率 = clamp(0.4 + 0.6·min(1, 能力/要求), 0, 1)
        × (0.6 + 0.4·忠诚/100) × 关系系数 × 中央权威

# 7 军事
战力 = 兵员 × 装备 × 训练 × 士气 × (1 + D/100) × 将领 × rand(0.85,1.15)
补给 = 路径最低容量 × (1 − 0.05 × 格数)；断线士气 −15%/回合，2 回合溃散

# 8 人口
ΔP  = P × (0.04·粮安 − 0.03·拥挤 − 0.02·疫病 + 0.01·医疗)
转化 ≤ 总人口 2%/年；迁移看 (工资 − 物价 + 满意度/5 − 通行成本) 差

# 9 抽卡
seed = SplitMix64(worldSeed ⊕ hash(entityId) ⊕ hash(namespace))
稀有度 55/30/12/3；第 10 抽保底杰出+
```
