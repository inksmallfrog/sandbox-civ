# 开发里程碑与验收（ROADMAP v0.1）

原则：**先把三条公式跑通，再堆内容。** 每个里程碑必须能被无头模拟证明，而不是被截图证明。

## 风险与预案

1. **复杂度失控**（最大风险）：任何新系统若不能表达为"三条公式 + 耦合表的一行"，不进主线，做 DLC。每里程碑做一次"逻辑量盘点"（代码行数/规则条目数）并写入 `CHANGELOG-DESIGN.md`。
2. **唯一最优解**：M5 起每里程碑跑多策略基线模拟，若某策略胜率 > 55% 即视为经济标定未完成，不许前进。
3. **性能**：M4 前完成 500 城镇 × 200 回合的 headless 时间剖面；不达标则把逐镇模拟改为分层聚合（阶级聚合变量本就是为此准备的降级路径）。
4. **存档演进**：M3 起每次结构改动附迁移器 + 旧档回归，破存档的提交必须打 `[破存档→已附迁移器]` 标签。
