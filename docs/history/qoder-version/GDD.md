## 0. 设计立场：先用三句话把复杂度压住

README 当前的写法是 **8 阶级 × 7 子系统（镇 6 + 国 8）× 3 经济循环**，直接实现会得到上百个交互点。本方案把它压缩成 **"三条公式 + 一张耦合表 + 一个瓶颈资源"**：

| 骨架 | 内容 | 覆盖的玩法 |
|---|---|---|
| 公式一 **转化式** | 投入 → 产出（受技术、地块、状态修正） | 农工商、科研、文化、军备，全部用它 |
| 公式二 **价格式** | 供需差 → 价格 → 再分配 | 城镇内循环、国内循环、国际循环共用同一条，只换参数 |
| 公式三 **满意式** | 满足率 − 期望 + 政策倾斜 + 软性压制 | 阶级矛盾、罢工抗税暴动、军队溃散、附庸离心 |
| 耦合表 | 每个阶级/政策写成"谁受益、谁受损"的向量 | 玩家的所有抉择 = 选牺牲谁 |
| 瓶颈资源 | **政令点 AP**（由官僚阶级供给） | 管理、军事、外交、建设的总量闸门 |

这样八个阶级**不需要八段代码**，只需要八行数据；三个经济循环**不需要三套市场**，只需要一个求解器配三种开放度。

### 0.1 对 README 的三处修正（带行号）

## 1. 基本框架

- **视角与尺度**：2D 六边形大地图，玩家扮演国家意志（不是某个城镇）。时间从"城邦时代"到"工业前夜"，约 120–200 个回合。
- **回合结构**：主模式为**回合制**（半实时暂停为可选皮肤）。理由：回合边界是天然的插件 hook 点、联机无延迟敏感、确定性回放可做。
- **一个回合 = 五个阶段**，所有系统都挂在阶段上：
  1. 意图阶段（玩家/AI 官员提交命令，消耗 AP）
  2. 生产阶段（地块 → 物资；科研/文化/宗教产出）
  3. 分配阶段（税、俸、饷、工资、价格结算、市场出清）
  4. 消费与状态阶段（需求满足 → 满意度 → 阶级状态迁移 → 增长/迁移/流失）
  5. 结算阶段（军事解算、事件、外交、名人产出、存档校验）
- **随机性来源（README 的"抽卡快乐"）**：地图生成、名人池刷新与征辟、事件抽取、灾害与天气、战斗方差、市场扰动项。所有随机都走分层确定性 RNG（见 `ARCH.md`），保证"随机但不不可解释"。
- **可解释性铁律**：任何结算结果必须能在 UI 里展开成一条链：`结果 ← 公式 ← 各项数值`。玩家看到"粮价 +18%，因为北境干旱 −22% 供给 + 军队征粮 +9% 需求"。这是 README"让玩家理解发生了什么事"的实现方式。

## 2. 地图与地块

### 2.1 分层，而不是枚举

一个地块由 5 层组成，每层只回答一个问题：

| 层 | 取值 | 作用 |
|---|---|---|
| 地表 | 平原/草原/森林/丘陵/山地/荒漠/湿地/冻土/海岸 | 基础产出与通行基础成本 |
| 水体 | 无 / 河(有向+流量) / 湖 / 海 | 水运、断水、渔业、隔断 |
| 形胜（Landform） | 盆地/山谷/隘口/河口/三角洲/上游高地/湖岛/绿洲/峡谷/盐湖/冲积扇/沼泽泽国/火山 | 战略锚点，见 2.3 |
| 资源标记 | 铁/马/香料/石/渔汛/渔盐（可空） | 只做"门槛与倍率"，不是新货币 |
| 人造 | 道路/驿/城/坞堡/堤坝/船坞/关城/矿区/种植园 | 玩家的物理意志 |

地块对外只暴露 **三个可计算属性**：

```
产出力 Y = 地表基础 × 形胜倍率 × 资源倍率 × 改良等级 × 水利系数
通行补给 C = 地表成本 × 形胜修正 × (道路 ? × 水运 ?)
防御 D = 地表防御 × 形胜防御 × 工事等级
```

玩家看一张图就能读懂，规则书只需三行。

### 2.2 基础物资（只有 5 个数）

**粮 / 料 / 器 / 奢 / 银**。

- 粮：人口与军队的生存品，价格最敏感。
- 料：木石矿陶的合并类（避免"十种矿产"）。
- 器：工具、布匹、建材、武器、书籍的合并类（科技只改"器"的品质系数，不加新品类）。
- 奢：奢侈品，满意度与文化的燃料，也是贵族囤积物。
- 银：硬通货。国内是货币（成色可改 → 通胀），国际是唯一结算手段（顺差 → 银流入 → 货币扩张 → 物价上涨 → 城市阶级不满）。
- 战略门槛：铁、马、香料不进"第 6 种资源"，而是**门控标签**（无铁不能重甲、无马不能骑兵、无香料则奢侈品产出上限低）。这样资源表永远只有 5 行。

### 2.3 形胜（README 点名的趣味地形）

| 形胜 | 生成 | 经济与后勤 | 军事与政治 |
|---|---|---|---|
| **盆地** | 环形高地包围 8–20 格内低地 | 内部 Y 高、人口上限高；唯一出口 → 自给型农业区 | 出口被围即"瓮城"：断粮可破，不需攻城；易成文化孤岛（宗教/方言标签） |
| **山谷** | 两山夹长槽 6–15 格 | 料/铁主产区 | 走廊行军，两侧高地可射击；一支小队即可锁谷 |
| **隘口 / 山水夹缝** | 河切穿山脊形成的 1–2 格孔洞 | 可设**税关**（过路费收入） | 战略核心：1 营可拒万军；谁占隘口谁定国界 |
| **河口** | 河入海 | 渔 + 外贸双加成，最佳建城点 | 封锁河口 = 掐死一个国家的进出口 |
| **三角洲** | 大河末端 | 全图最高 Y，但每 8–20 回合一次洪水 | 人口爆点，也是饥荒爆点（高风险高回报） |
| **上游高地** | 河源头段 | Y 一般 | 可筑坝/排污 → **对下游断水**，非军事施压手段，天然外交冲突 |
| **峡谷** | 深窄河谷 | 可筑坝 → 水力（器 产出倍率） | 天然关城位 |
| **湖岛 / 半岛** | 湖中或海中 | Y 低但免灾害 | 学术/宗教隐居地（研究、信仰加成）；陆军不可直取 |
| **绿洲** | 荒漠中成串 | 补给点 | 控制绿洲 = 控制穿越荒漠的商路（沙漠变"高收益高风险通道"而非空无） |
| **盐湖 / 盐田** | 内流湖末端 | 盐（早期算"奢"，改良技术后算"必需"） | 盐铁专卖的玩法载体 |
| **冲积扇 / 梯田位** | 山前与丘陵坡 | 需改良才可高 Y | 体现"人定胜天"科技线，投资换长期 |
| **沼泽** | 低洼排水不良 | 渔、药，粮极低 | 骑兵禁用、行军成本翻倍、疫病 → 天然战略阻滞带 |
| **火山/地热** | 稀有 | 特殊"料"倍率 + 灾害 | 信仰圣地标签 |

### 2.4 河流与水利（一条规则撑起很多玩法）

河是有向图 `source → … → sea/lake`，每段有 `flow`。三条推论：

1. **水运**：沿河移动/运输成本 ×0.4，河段间航运比陆路便宜 3 倍 → 商路与税关自然聚在河运节点。
2. **梯度传导**：上游 `坝/污染/取水` 按比例削减下游 `flow`，下游 Y 与卫生（疫病概率）随 flow 变化。玩家能看见"上游修坝，下游三镇粮减产"。
3. **渡口与桥**：河宽由 flow 决定，浮桥/渡口是稀缺格 → 战斗与贸易同时受制约。

## 3. 城镇：阶级即人口系统

城镇是独立子系统，一个城镇 = `地块集合 + 人口（分阶级）+ 建筑 + 库存 + 政策槽 + 官员槽`。

### 3.1 阶级统一模板（八阶级共用，只有数值不同）

```
L_c   = Pop_c × 劳动系数 × 状态修正            // 可用劳力
Out_c = Σ 转化式(投入L_c, 地块Y, 技术, 建筑)     // 公式一
Need_c= Pop_c × (生存需求 + 阶级专属需求)         // 粮/料/器/奢/服务
s_c   = min(1, 实际获得 / Need_c)               // 满足率
Sat_c ← Sat_c + k1·(s_c − 期望_c) + k2·(−税负) + k3·政策倾斜 + k4·软性压制 − 衰减
Org_c = 组织度(行会/庙宇/学宫/军制 + 名人代言)
Pow_c = Pop_c × Org_c × 财富集中度              // 政治分量
状态_c ∈ {服从(>55) | 抱怨(30–55) | 反抗(<30)}
```

`反抗` 按 `Pow_c` 与镇内可控力（军队、警察、信仰）判定升级为：**怠工（产出 −15%）→ 罢工/抗税（产出 −40%，税收 −50%）→ 暴动（城镇控制权倒计时，需镇压或让步）**。这是 README 要的"阶级矛盾影响城镇发展策略"的唯一实现点，不再另加机制。

### 3.2 八阶级定义表（数据，不是代码）

| 阶级 | 投入 | 产出（转化式） | 主要消耗 | 解锁条件 | 专属功能 | 天然矛盾 |
|---|---|---|---|---|---|---|
| **农民** | L + 地块Y | 粮、料 | 粮、料(农具) | 初始 | 人口自然增长主力（增长 = Pop × 余粮 × 住房） | 商人(粮价)、官僚(税) |
| **工人** | L + 料 | 器（工具/布/建材/兵器） | 粮、器 | 作坊区 + 器需求 > 阈值 | 一切装备与建筑升级的前提 | 商人(物价/工价)、官僚(管制) |
| **商人** | 资本 + 信息差 | **流通效率**（把库存变现、拉平镇际价差） | 奢、服务 | 市场建筑 + 与另一镇连通 | 跨镇运输、外贸执行者 | 农民(粮价)、官僚(专卖/抄没) |
| **官僚** | 职权 | **行政能力 = AP 容量**、税执行率 | 俸(粮+器)、奢 | 城镇规模阈值或国家层级建立 | 决定政令上限与执行折扣；腐败漏税 | 一切被管者；学者(晋升) |
| **祭司** | 仪式 | **凝聚力**（满意度阈值下移）、教化(→研究效率前置) | 粮/奢(祭品)、庙 | 定居 + 出现剩余 | 用信仰替代钱：缺粮时压住反抗升级 | 学者(真理来源)、官僚(免税权) |
| **学者** | 研究时间 | **研究点**、名人吸引率 | 器(书/仪器)、奢(供养) | 藏书阁/学宫 + 供养剩余 | 修改生产函数本身；技术外流载体 | 祭司、官僚(审查) |
| **军人** | 武备 + 粮饷 | **安全**（战力、屯田、治安） | 粮、器(装备)、饷 | 铁或马 + 威胁值 | 镇压反抗与对外作战；满意度直接决定边境稳定 | 商人(粮价)、官僚(克扣饷银) |
| **文艺家** | 灵感 + 供养 | **文化值**、幸福、名人吸引率 | 奢、服务 | 城市规模 + 剩余 + 宫廷/市民需求 | 文化辐射：独立城镇归心、附庸忠诚 | 官僚(审查)、祭司(风化)、学者(抢赞助) |

解锁顺序（文明演进的骨架）：农民 → 工人 → 商人 → 祭司 → 官僚 → 学者 → 军人（民兵制 → 常备制）→ 文艺家。每次解锁都伴随一次结构性矛盾（例：商人解锁后粮价不再被行政压制 → 农民不满上抬），玩家必须处理新变量，这是"逐步丰富"而不是"堆内容"。

### 3.3 阶级耦合表（政策=向量）

每条政策/价格变动都写成：

```
policy: { 名称, AP成本, gains:[(class, +ΔSat, +ΔPow)], losses:[...], effects:[...] }
```

例：**平粜（国库抛售存粮平抑粮价）** `AP 3 | gains: 城市工人+8, 军人+6, 农民−10 | losses: 商人−12 | effects: 粮价 −20%, 库存粮 −N`。玩家永远在做牺牲谁的选择，而系统只多了一张表。

### 3.4 增长与迁移

- 增长：`ΔPop = Pop × (r0 × 余粮满足率 × 住房满足率 − 拥挤惩罚 − 疫病)`。
- 迁移：按相邻镇 `实际工资 − 物价 + 满意度 − 通行成本` 差值流动；阶级不同敏感度不同（商人看利润、农民看税负、学者看机构）。人口是**会投票的流体**，玩家的地价政策会直接被迁移惩罚。

## 4. 经济三循环（一个求解器）

统一市场出清式（公式二）：

```
price' = clamp( price × (1 + α × (D − S) / max(S, ε) + ε_t) ,  floor, cap )
```

| 循环 | 层级 | α（价格弹性） | 库存主体 | 介入手段 | 主要玩法 |
|---|---|---|---|---|---|
| 城镇内循环 | 单镇 | 0.30 | 镇仓 | 限价、配给、徭役、平粜 | 阶级失衡、产业结构自发演化 |
| 国内循环 | 全国市场 | 0.15 | 镇仓 + 国库 | 税率、专卖、国债、铸币成色、道路投资 | 区域分工、财政平衡、通胀 |
| 国际循环 | 世界市场 | 0.08 | 各国国库 | 关税、禁运、补贴、外汇(银)、条约 | 顺差/逆差、封锁与走私、资源卡脖子 |

- **国内价格**是各镇价格按运输成本加权的加权均衡，不是凭空的国家价。道路与河运投资会真实地把两个镇变成一个市场。
- **不保证平衡**（README 明确要求）：内循环会让某阶级衰弱、某阶级壮大。默认演化剧本：农业剩余集中 → 农民满足崩 → 粮产下降 → 商人囤积 → 城市粮价暴涨 → 工人/军人反抗 → 需要玩家干预（限价/抄没/宗教安抚/对外抢粮）。
- **白银传导链**（国际循环的核心闭环）：出口 → 银入 → 货币供给↑ → 物价↑ → 收固定俸禄的官僚与吃饷的军人不满↑ → 需要调俸或通胀税。逻辑四行，现象很"文明"。

## 5. 国家系统

### 5.1 国家与城镇的关系

城镇有 4 种归属状态，用**一组系数**表示（不是四套规则）：

| 归属 | 税抽取 | 征兵征粮 | 政策强制度 | 特点 |
|---|---|---|---|---|
| 直属 | 100% | 是 | 1.0 | AP 消耗高，需官僚 |
| 自治 | 55% | 有限 | 0.6 | 地方强宗加成，叛离风险 |
| 附庸 | 35% + 贡 | 否 | 0.4 | 提供缓冲与朝贡收入 |
| **独立** | 0 | 0 | 0 | 中立市场、走私通道、文化归附靶子 |

独立城镇是本设计的"第三方棋子"：可被文化辐射吞并、被金钱收买、被封锁饿服，也是战争的缓冲区与情报中转站。

### 5.2 管理系统（官僚）— 国家能力

- **AP（政令点）**：`容量 = 官僚Pop × 行政效率 × (1 − 腐败) × 中央权威`。所有政策、建设、外交、军事指令消耗 AP。**超出容量不是禁止，而是打折执行** → 帝国的边界由官僚数量与廉洁度决定，天然解释"为什么打下来管不了"。
- **税执行率**：`实收 = 税基 × 执行率`，执行率来自负责征税的官员能力与忠诚、道路与驿站、腐败。漏收的部分变成官僚财富（他们满意度↑，国库↓）。
- **腐败度**：一个 0–1 的状态量，受俸禄满足度、监察机构、名人的负面特质（贪）、宗教/文化约束影响。高腐败 → 执行折扣大 → 玩家会主动反腐，反腐又得罪官僚 → 回到阶级矛盾。

### 5.3 政治系统与官员任命（与第 6 章咬合）

- **权力结构**（政体）不是枚举，由三个量决定：`王权 / 官僚 / 地方贵族(大地主大商人) / 院(祭司+学者+文艺家)` 四方影响力 `Pow`。谁的 `Pow × 忠诚度` 最高，谁决定摄政与继承规则。
- **权威（Authority）**：国家总闸门，由军事胜利、财政健康、官僚满意、国教一致、文化声望供给。权威低 → 政令执行折扣、附庸离心、名人投奔他国。
- **议会/廷议**：每 N 回合一次，按 `Pow` 加权表决政策包，玩家可否决但付出满意代价。这替代了"民主/专制"这种枚举标签，逻辑上仍是同一张耦合表。

### 5.4 宗教（祭司）

- 信仰不是数值 buff 集合，而是**满意度阈值下移器**：有国教时，反抗门槛从 30 → 20，且缺粮时祭司可"施粥/讲经"临时压制暴动（钱不够时用信仰顶）。
- 传播：`速度 = 祭司数 × 庙宇 × 距离衰减 × 抵抗`；异端分布造成"同一政策在不同镇效果不同"（与上令不下达共用一条执行链）。
- 三条路线：国教压制（快但埋分裂）/ 多教并存（稳定但信仰效果弱）/ 世俗化（释出庙产与祭司 Pow，换取学者与商人加成 + 宗教福利消失）。

### 5.5 科技（学者）

- `研究点 = 学者Pop × 供养系数 × 机构 × (1 + 教化加成)`；科技 = **修改转化式的参数 + 解锁 hook 的条件**，不引入新机制。
- 关键节点示例：堤坝（三角洲安全）、犁与轮作（粮倍率）、文字与历法（祭司 → 教化）、印刷（学者与文艺家同时受益）、冶炼/马镫（兵种门控）、股份制与复式记账（商人资本上限）、水闸/船坞（海军）、纸钞（货币可控，但可通胀）、火器（ siege 与隘口价值重估）。
- **技术外流**：学者与名人叛逃会把他国科技带走 → 与名人系统和间谍共用一条链。

### 5.6 军事（军人）

- 军队 = `兵员(军人Pop) + 装备(器) + 粮饷 + 补给线 + 将领(名人)`。
- **补给线**是本设计的地形价值兑现点：`补给能力 = 路径(道路/河运)最低容量 × 距离衰减`。断线 → 士气每回合 −15%，两回合后溃散；这就是"占隘口、烧粮道、淹下游"比"数值对撞"更有趣的原因。
- 战斗解算（自动 + 将领先手）：`战力 = 兵员 × 装备系数 × 士气 × (1 + D_def/100) × 将领修正 × 随机扰动`。以**士气崩溃**为败北判定，不做全歼；败方退入工事可重整。
- 兵种只用"装备等级 × 地形许可"生成，不做 30 种兵：轻步/重步/弓/骑/甲骑/攻城/辎重/船，八个，全部由同一模板配不同参数。
- 战争目标（与外交结算挂钩）：占领、封锁隘口/河口、断水、掠夺、附庸化、占领首都。

### 5.7 艺术与外交

- **文化值**：产出（文艺家 + 建筑）→ 声望 → 三处生效：独立城镇归附概率、附庸忠诚、他国城镇的"向往"（提高其不满，不花一分军费的软进攻）。
- **外交**：关系值、条约（贸易/通行权/互不侵犯/同盟/朝贡/技术援助）、宣战理由、背信用（影响后续缔约成功率）、附庸体系、国际会议、间谍（偷科技、煽动他国阶级矛盾、收买名人）。

### 5.8 国库

- 收入：土地与人头税、专卖、关税、铸币息/通胀税、贡金、罚金与抄没。
- 支出：军饷、官俸、基建、平准储备、补贴、偿债。
- 危机：违约 → 军人与官僚同时崩（最危险的组合）；滥铸 → 通胀 → 城市阶级崩；平准储备耗尽 → 灾年无粮可抛 → 暴动。国库是三个满意式变量的公共上游，因此它天然是全局压力锅。

### 5.9 终局

计分三轴：**霸业**（领土与附庸）、**繁荣**（贸易网络中心度 + 国库）、**文明**（科技与文化辐射）+ 时限计分（生存模式）。胜利条件为三轴的阈值而非单一目标，避免"只有一种玩法最优"。

## 6. 名人与征辟（抽卡系统）

README 最原创的一块，也是把政治、军事、经济、文化**用一个实体串起来**的枢纽。

### 6.1 结构（一个名人 = 一行数据）

```
名人 = {
  四维: 理政 / 筹策 / 军功 / 声望        // 只四维，不十维
  阶级代言: 出身阶级                      // 决定立场与政策倾斜
  特质: 1 正 + 1 负（稀有度决定可 3）      // 负特质必须是行为触发器
  技能: 从所属阶级的技能池随机抽取
  关系网: 与其他名人的 ±值（师生/姻亲/政敌/同党）
  野心 & 忠诚 & 疲劳（随任期变化）
}
```

特质样例：`贪`（财政泄露，但若被派去收专卖税收入反而最高）、`骄`（拒不执行与自己政敌相关的政令）、`能臣`（执行折扣归零）、`篡`（拥兵自立倒计时）、`清流派`（降全国腐败但得罪所有官僚）、`通商`（外贸 α 提升）、`屯田`（军粮自给）。

关键：**负面特质不是风味文字，会真实改变结算**，所以"抽到强但危险的人"是抉择而不是数值比较。

### 6.2 抽取循环（快乐从哪来）

- 每回合各城镇按 `学者/文艺家/祭司/退休官员` 的吸引率生成"在野名人"入池；池有刷新与过期。
- 玩家用 **察举/征辟**（消耗 AP + 国库）抽取：白/蓝/紫/金四档，权重受国策影响（崇文 → 学者与文艺家卡权重上升；穷兵 → 军人卡上升）。
- 10 连保底一档稀有；**时代卡包**（城邦包、铁器包、火药包、商业包）= 新特质与新技能的数据包，内容扩展不改逻辑。
- 抽取结果即时可见地"落到某个 slot"：抽到一个 `屯田` 军人，界面直接告诉他"军粮自给率 +20%，边镇扩张可行"——随机性与规划相连，而不是纯数值惊喜。

### 6.3 任命与"上令不下达"

```
政策效果 = 基础效果 × (0.5 + 0.5 × 官员能力/职位要求) × 忠诚系数 × 关系系数 × 中央权威
```

- **关系系数**：与政策受益方是政敌 → 打 7 折；同党 → 1.15 倍。
- 同一道政令在不同官员治下结果不同，UI 展示为"执行链报告"（谁执行、每项折扣来自哪个特质或关系）。玩家于是会做真实决策：把政敌调去执行他反对的政策，代价是什么？
- **诉求机制**：名人按野心与处境周期性提出诉求（要权、要钱、要免税、要娶、要整倒某人）。满足 → 忠诚↑、能力释放；拒绝 → 消极、结党、投奔他国（带走科技）、甚至发动政变（与权威值、军队忠诚共同判定）。

## 7. 随机性与事件

事件 = 数据包：`{触发条件, 权重, 阶级向量, 3 选项(各带 AP 与代价)}`。事件不写代码，只写表。

类型：天灾（洪水/蝗灾/瘟疫/地震）、丰收、继承危机、名臣降临、大罢工、行会请愿、学宫辩论、异端运动、边患、 discoveries（新资源/新形胜）、他国使团、商队被劫（外交事件生成器）。

设计约束：每个事件必须至少影响 **两个阶级的满意度** 或 **一种物资价格**，否则没有决策价值，不写。

## 8. 联机与 AI

- 本地：单人 + 热座（回合制天然支持）。
- 在线：服务器/主机权威 + **只传命令流**（见 `ARCH.md`）；同时回合 + 结算倒计时；定期状态哈希校验，不同步时回放定位。
- **断线托管 = 复用名人代理系统**：AI 用玩家本国官员的决策函数接管，玩家回来接回。一套决策函数同时服务"官员替玩家决策"、"AI 国家"、"托管"三种场景，是本设计最大的逻辑量节省。

## 9. 首章可玩闭环（垂直切片验收标准）

30 分钟内必须出现：

1. 选城址（河口的 Y 与外贸优势 vs 盆地的安全 vs 隘口的税关收入）；
2. 一次阶级解锁（工人 或 商人）带来的结构性不满；
3. 一次粮价危机，玩家选：限价（得罪商人 + 未来短缺）/ 平粜（耗国库）/ 镇压（需军人与忠诚代价）/ 让祭司安抚（宗教 Pow 上升，埋 later 隐患）；
4. 一次征辟抽卡 + 一次任命，玩家看见同一条政令在两个镇执行结果不同。

这四条分别是地图、阶级、经济、名人四个系统的"最小可感证明"。缺任何一条都不算切片完成。
