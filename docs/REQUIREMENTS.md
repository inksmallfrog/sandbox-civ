# 概况
这是一个待启动的游戏项目，人类只提供设计思路，细节完全由AI实现。
# 总体要求
游戏要有随机性，能体验到“抽卡”的随机快乐。玩法尽量丰富，但内部逻辑要尽量保持简洁，至少让玩家能够理解发生了什么事。

# 设计要求
## 游戏类型
一款2d的基于城镇系统的策略类文明发展游戏，支持本地和在线联机，未来拟投入steam发布的游戏。
游戏引擎完全由AI决定。开发需用git同步代码，每次完成关键节点时强制用git提交。第一个AI需制定明确的开发文档，以便后续ai能知道怎么继续完成开发。
游戏应保持一个能独立运行，最基础的core系统，包含游戏最基础、尽可能精简的核心系统。
初core以外的功能均需以插件形式实现。

## 游戏设计
游戏包含以下核心系统：
### 地图与地块
游戏应基于一个世界地图，世界地图需随机生成，计划设计为六边形网格地块地图，每个地块有不同地形（类似文明6的系统），不同产出。请帮我设计地块种类，以便丰富后期地块管理，军事调度等玩法。地图需包含河流、湖泊、海洋地块（根据设计需要，可以用同一种地块），可以考虑设计成出盆地、山谷、山水夹缝等有趣味性，适合策略的地形。
### 城镇
城镇是游戏的基础，要随着AI或玩家经营逐步发展。
一个城镇应作为一个完整的独立子系统存在。其包含的系统如下：
#### 阶级系统（人口系统）
一个城镇内的人口区分为不同阶级。包括官僚、农民、工人、商人、祭司、学者、军人、文艺家八个级阶，但这些阶级并不是初始全部存在，应该根据文明的发展按条件逐个解锁。
不同的阶级有不同的消耗和产出，并能实现不同功能。
每个阶级作为一个独立的子系统，拥有独立的阶级运行逻辑，请在尽可能简洁的情况下，设计各阶级运行逻辑。并设计一个通过阶级矛盾影响城镇发展策略的系统。
#### 经济系统（主要依赖农、工、商阶级）
尽可能在逻辑简洁，易于理解的前提下，设计出符合真实世界的经济系统。
要包含：城镇经济内循环，国内经济内循环，国际经济外循环三个经济循环系统。
##### 城镇经济内循环
城镇各阶级的经济能够实现内循环，但内循环不必保证各阶级平衡，如果内循环会导致某阶级衰弱，某阶级壮大，并因此产生不同增益或负面效果，反而更符合真实发展规律。这时就需要玩家制定相应发展策略，进行城镇发展平衡性规划，可玩性更高
##### 国内经济内循环
主要通过国内城镇市场贸易系统，和国家财政平衡实现。
##### 国际经济外循环
允许城镇与他国城镇交易，设定合理的城镇间外贸交易逻辑。

### 国家
国家作为玩家代入视角，玩家将在游戏中与其他AI操控或联机玩家的国家进行竞争与合作
一个国家拥有至少一个城镇，可以建设新城镇。但一个城镇不一定属于一个国家，允许有无附属的独立城镇存在。
需设计好国家与城镇间的交互关系，特别是阶级与经济的关系。
#### 官员（名人）系统
从各城镇各阶级中将不定期随机产出名人，名人有不同属性、政治倾向、决策逻辑，还有不同特色技能（随机刷新，但会受所属阶级的影响）。国家可以选举名人，担任各个系统的官员或管理城镇，名人将替玩家进行决策，并根据需要提出发展建议或诉求。
名人要有自己的诉求和倾向（包含正面和负面），并拥有独立的人际关系。其个人倾向，人际关系也会影响其决策，并有可能产生上令不一定下达的效果，增加游戏玩法的戏剧性和多样性。比如，玩家可能抽取到特别强的名臣，自动解决很多发展问题，或抽到特别强的军事统领，胜仗概率极高。也有可能抽到贪官，或能力强但容易造反的名人。
